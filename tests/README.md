# 장치 테스트

장치를 하나씩 확인하고, 그 결과로 설정값(TODO)을 채운다. 값의 의미는 [../README.md](../README.md) 3절.

## 공통
- **mission 폴더(`~/picar_mission`)에서** 실행한다: `python3 tests/test_xxx.py`
- 먼저 웹 컨트롤러를 끈다 (같은 모터 칩·웹캠·초음파 핀을 씀)
  ```bash
  sudo systemctl stop Adeept_Robot.service
  ```
- 테스트는 한 번에 하나만 실행한다
- 종료: `q` 또는 Ctrl+C

추천 순서: 카메라 → 팔 → 초음파 → 바퀴

## 1. 카메라 `test_camera.py`
```bash
python3 tests/test_camera.py
```
PC 브라우저에서 **`http://192.168.50.2:5001`** 접속 → 웹캠 화면. QR이 보이면 화면 왼쪽 위와 터미널에 글자가 나온다.

| 확인할 것 | 결과로 채울 값 |
|---|---|
| 화면이 나오는지, 위아래가 뒤집혔는지 | (안 나오면 `hw.CAMERA_INDEX`) |
| 출발 QR이 `LEFT` / `RIGHT` 그대로 읽히는지 | `qr.py` 의 `wanted` |
| 출발선에서 QR이 읽히는 팔 위치 | `qr` 자세 (팔 테스트에서 저장) |
| PICK / PLACE QR이 읽히는지 | (나중에 팔 위치 맞출 때 사용) |

주의: 이 테스트가 켜져 있는 동안 다른 테스트에서는 카메라를 못 쓴다.

## 2. 팔(지그) `test_arm.py`
```bash
python3 tests/test_arm.py
```
시작하면 팔과 집게를 90°로 보낸다.

| 명령 | 뜻 | 예 |
|---|---|---|
| `<채널> <각도>` | 그 각도로 이동 | `2 120` |
| `<채널> +<n>` / `-<n>` | 지금 각도에서 더하기/빼기 | `2 +5` |
| `show` | 현재 각도 | |
| `save <이름>` | 현재 팔 자세(채널 1~3) 저장 → `poses.json` | `save left_pick` |
| `go <이름>` | 저장한 자세로 이동 | `go drive` |
| `list` | 저장한 자세 목록 | |
| `q` | 종료 | |

| 확인할 것 | 결과로 채울 값 |
|---|---|
| 채널 1~4가 각각 어느 부위인지 (`1 +20`, `1 -20` …) | `hw.py` 의 `SERVO_ARM_ROT` ~ `SERVO_GRIP` |
| 각 채널이 기구 끝에 걸리는 각도 (소리 나기 직전) | 자세 저장할 때 그 안쪽으로 |
| 집게가 열리는 각도 / 물체를 잡는 각도 (`4 <각도>`) | 웹 페이지에서 mode 별 `grip_open`, `grip_close` 로 저장 |
| 공통 자세 `drive`, `qr` | `poses.json` (mode 별 위치 4곳 + lift 는 웹 페이지에서, ../README.md 4절) |

팁: 처음에는 `+5` 처럼 조금씩. 서보가 "지잉" 하고 버티면 바로 반대로 돌린다.

## 3. 초음파 `test_ultrasonic.py`
```bash
python3 tests/test_ultrasonic.py
```
0.2초마다 출력: `raw` = 한 번 잰 값, `median` = 5번 재서 중앙값 (정지 후 위치 확인에 사용하는 방식).

| 확인할 것 | 결과로 채울 값 |
|---|---|
| 자로 잰 거리와 비슷한지 (예: 30cm, 50cm 에 물체) | 차이가 크면 배선·센서 각도 확인 |
| raw 가 얼마나 튀는지, median 은 안정적인지 | 튀면 `distance_median(n)` 의 `n` 키우기 |
| **초음파 센서를 빨간 정지선 위에 두고** 모니터까지 median 값 | `drive.py` 의 `DISTANCE_OFFSET_CM` 보정 (실제 30cm - 센서값) |

모니터 화면은 매끈해서 각도가 비스듬하면 값이 튈 수 있다. 정면으로 둔다.

## 4. 바퀴 `test_motor.py`
```bash
python3 tests/test_motor.py
```
**처음에는 차를 바닥에서 띄우고** 실행한다.

| 명령 | 뜻 | 예 |
|---|---|---|
| `f <속도> <초>` | 앞으로 (속도 0~100) | `f 30 1` |
| `b <속도> <초>` | 뒤로 | `b 30 1` |
| `st <오프셋>` | `STEER_CENTER` 기준 조향 | `st -30`, `st 0` |
| `sa <각도>` | 조향 각도 직접 | `sa 85` |
| `q` | 종료 | |

| 확인할 것 | 결과로 채울 값 |
|---|---|
| `f 30 1` 에서 두 바퀴 모두 앞으로 도는지 | 뒤로 도는 쪽 `hw.py` `M1_DIR`(왼쪽) / `M2_DIR`(오른쪽) 부호 바꾸기 |
| `st -30` 이 왼쪽인지 오른쪽인지 | `hw.steer()` 주석 |
| 바닥에서 `f 30 2` 로 똑바로 가는 조향 각도 (`sa` 로 바꿔가며) | `hw.py` 의 `STEER_CENTER` |
| 느린 속도부터 달려 보고, 멈췄을 때 밀리는 거리 | `drive.py` 의 속도 3단계와 `BRAKE_ADVANCE_CM` |

너무 낮은 속도(예: 10 이하)는 모터가 힘이 부족해 안 돌 수 있다.
